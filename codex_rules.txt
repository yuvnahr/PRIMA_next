PRIMA-NEXT Engineering Constraints

1. Use Python 3.12.
2. Use strict typing.
3. Use dataclasses or pydantic models.
4. No circular dependencies.
5. Dependency injection only.
6. No global singletons.
7. No direct subsystem coupling.
8. Workflow layer owns orchestration.
9. Event bus owns asynchronous communication.
10. ChromaDB remains source of truth for memory.
11. All public APIs documented.
12. Unit tests required.
13. Security-first design.
14. Async-compatible implementation.
15. Preserve existing benchmark behavior.
16. Preserve existing affect behavior.
17. Preserve existing memory behavior.
18. Preserve existing reflection behavior.
19. Backward compatibility adapters where needed.
20. Code must pass mypy, ruff, pytest, and bandit checks.
